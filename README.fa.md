# نقشه راه یادگیری هوش مصنوعی عامل‌محور (Agentic AI)

این مخزن مسیر یادگیری عملی برای ساخت عامل‌های هوش مصنوعی را با استفاده از پایتون، مدل‌های زبانی بزرگ (LLM)، سرویس OpenRouter، ابزارهای LangChain و LangGraph و پروتکل MCP مستند می‌کند.

## تفاوت چت‌بات و عامل هوش مصنوعی چیست؟

یک چت‌بات معمولی عمدتاً به پرسش‌ها پاسخ می‌دهد:

```text
کاربر
  ↓
پرسش
  ↓
مدل زبانی بزرگ (LLM)
  ↓
پاسخ
  ↓
پایان
```

یک عامل هوش مصنوعی هدفی دریافت می‌کند و برای رسیدن به آن تلاش می‌کند:

```text
هدف کاربر
  ↓
استدلال و تصمیم‌گیری
  ↓
استفاده از ابزار
  ↓
ارزیابی نتیجه
  ↓
تصمیم‌گیری درباره گام بعدی
  ↓
تکمیل کار
```

تفاوت اصلی:

- **چت‌بات (Chatbot):** به پرسش‌ها پاسخ می‌دهد.
- **عامل (Agent):** برای انجام یک وظیفه اقدام می‌کند.

# عامل هوش مصنوعی چگونه کار می‌کند؟

یک عامل معمولاً در یک چرخه پیوسته کار می‌کند.

## ۱. درک محیط (Perception)

عامل موارد زیر را درک می‌کند:

- هدف کاربر
- اطلاعات موجود
- محیطی که در آن فعالیت می‌کند
- ابزارهای در دسترس

**مثال:**

> «برای امشب ساعت ۷، یک رستوران ایتالیایی خوب در نیویورک پیدا کن.»

عامل تشخیص می‌دهد که برای انجام این درخواست چه کارهایی لازم است.

---

## ۲. استدلال (Reasoning)

مدل زبانی بزرگ (LLM) نقش بخش تصمیم‌گیرنده عامل را ایفا می‌کند.

عامل تصمیم می‌گیرد:

- اولین قدم چیست؟
- به کدام ابزار نیاز دارد؟
- چه اطلاعاتی هنوز مشخص نیست؟
- بعد از این مرحله چه کاری باید انجام شود؟

**مثال:**

```text
باید:
۱. رستوران‌ها را جست‌وجو کنم.
۲. ظرفیت خالی را بررسی کنم.
۳. رزرو را انجام دهم.
۴. تأییدیه را ارسال کنم.
```

توجه: انجام رزرو یا ارسال تأییدیه به ابزار مناسب و مجوز لازم نیاز دارد.

---

## ۳. اقدام و فراخوانی ابزار (Action / Tool Calling)

این مرحله یکی از تفاوت‌های مهم عامل با یک چت‌بات ساده است.

عامل می‌تواند از ابزارهایی مانند موارد زیر استفاده کند:

- جست‌وجوی وب
- APIها
- پایگاه‌های داده
- اجرای کد
- ایمیل
- تقویم
- فایل‌ها و سیستم فایل

**مثال از جریان اجرا:**

```text
مدل زبانی بزرگ (LLM)
        ↓
ابزار جست‌وجو
        ↓
API رستوران
        ↓
ابزار رزرو
        ↓
ابزار ایمیل
```

عامل فقط متن تولید نمی‌کند؛ در صورت داشتن ابزار و مجوز مناسب، می‌تواند عملیات واقعی هم انجام دهد.

---

## ۴. ارزیابی (Evaluation)

پس از اجرای یک اقدام، عامل نتیجه را بررسی می‌کند.

**مثال:**

```text
نتیجه ابزار:
برای ساعت ۷ میز خالی وجود ندارد.
```

عامل ممکن است تصمیم بگیرد:

```text
ساعت ۷:۳۰ را امتحان کن
یا
رستوران دیگری پیدا کن
```

این روند، یک چرخه تکرارشونده ایجاد می‌کند.

# یک مفهوم مهم

هر برنامه‌ای که از LLM استفاده می‌کند، لزوماً عامل هوش مصنوعی نیست.

کد زیر فقط یک درخواست به مدل زبانی ارسال می‌کند و پاسخ می‌گیرد:

```python
response = client.chat.completions.create(
    model="model-name",
    messages=[
        {
            "role": "user",
            "content": "Explain AI agents"
        }
    ]
)
```

این به‌تنهایی یک **برنامه مبتنی بر LLM** است، نه لزوماً یک عامل.

برای ساخت عامل، معمولاً به قابلیت‌هایی مانند این‌ها نیاز داریم:

- ابزارها
- تصمیم‌گیری
- برنامه‌ریزی
- حافظه، در صورت نیاز
- حلقه اجرا و ارزیابی نتیجه

وجود همه این قابلیت‌ها در هر عامل الزامی نیست؛ طراحی به هدف پروژه بستگی دارد.

## مرحله ۷ — حافظه (Memory)

در این مرحله، قابلیت نگهداری و بازیابی اطلاعات را به عامل اضافه می‌کنیم.

نمونه اطلاعاتی که ممکن است نگهداری شوند:

- مکالمات قبلی
- ترجیحات کاربر
- اطلاعات پروژه

فناوری‌های مرتبط:

- پایگاه‌های داده برداری (Vector Databases)
- امبدینگ‌ها یا بازنمایی‌های برداری متن (Embeddings)
- تولید افزوده با بازیابی اطلاعات (RAG)

**نکته:** حافظه مکالمه و RAG دقیقاً یک مفهوم نیستند. RAG روشی برای بازیابی اطلاعات مرتبط از منابعی مانند اسناد است؛ حافظه می‌تواند اطلاعات مکالمه یا ترجیحات کاربر را هم نگه دارد.
